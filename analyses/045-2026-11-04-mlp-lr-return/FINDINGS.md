# MLP return-to-0.75x findings

Source: Run224 terminal evidence, reused Run223 fresh same-Spark controls, and source-verified results.json. This is a controlled, single-seed response experiment; causal comparison is between each return branch and its matching held-half branch.

- Both branches exactly reproduce their original Run223 histories through state650:139 boundary records covering loss, raw-gradient norm, rho, projected gradient change and parameter norm, plus138 complete actual-update records. Fork gradient and two-update tensor/moment/history/RNG replay pass. This isolates the subsequent LR change without restarting Adam.
- The0.5x-to-0.75x change is a50% increase in applied LR, although it remains below the original base LR. It starts with update650->651; no update is applied at endpoint800.
- Both held-half paths have zero >10% excursions after650. The return paths have7 (immediate-half history) and10 (cosine history), each including an unresolved endpoint excursion. The unchanged control has8, including one unresolved endpoint event. Counts alone conceal the much larger return transient.
- The first return excursions begin at664 and peak at671/672. Their peak/pre-rise ratios are9.01x and6.50x; maximum losses are0.13365 and0.09391, exceeding the unchanged control's post650 maximum0.04823. The response develops over multiple updates after the LR change, rather than appearing immediately at650.
- Relative to keeping the matching half LR, mean loss over651..800 rises57.41% for the immediate-half history and45.37% for the cosine history. Last32-state mean rises43.18% and25.03%; final loss rises33.05% and14.70%. All three measures favor holding half LR in this window.
- Raw rho, near+1 on the held-half paths, reaches approximately-0.999 on both return paths. Maximum post650 raw-gradient norms increase from0.00898/0.00880 to4.3388/3.5582. The projected-gradient-change diagnostic also becomes strongly oscillatory. These are recorded response diagnostics, not Hessian estimates or an Adam stability theorem.
- The earlier cosine reduction moderates the largest return transient compared with the abrupt-half history, but neither history prevents renewed spikes when LR is raised to0.75x at650. This weakens the hypothesis that the smooth low-LR period by itself makes this later LR increase safe. It does not test a gradual increase, other return times, other seeds or other models.
- Endpoint full-test loss is0.75072/0.75393 for the return branches versus0.75720/0.75849 for their held-half parents. These single-seed secondary outcomes prevent equating smoother training with guaranteed better test performance; no generalized held-out benefit is claimed.
