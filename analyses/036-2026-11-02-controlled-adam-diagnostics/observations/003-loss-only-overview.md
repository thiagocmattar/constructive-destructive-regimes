# Training-loss-only Adam overview

The author requested retaining only the first row of
[adam_manuscript_overview.pdf](../figures/adam_manuscript_overview.pdf).
The figure is regenerated by [05_plot_loss_overview.py](../05_plot_loss_overview.py).
Its [manifest](../loss_overview_manifest.json) pins sources and output identity.

Sources: the loss arrays in `archive/paper_evidence/presentation_manifest.json`,
verified against all nine original Run215 `boundaries.jsonl` files and the run's
completion results. The earlier three-row PDF remains available in Git history.
No archived analysis or manuscript copy is modified.

Caption: Full-objective training loss under Adam at three constant learning
rates per model. Columns show CIFAR-10/MLP, CIFAR-10/ResNet-32 and
WikiText-2/Transformer. All nine trajectories start from their case's same frozen
initial weights and run for 1,024 updates. Loss is unsmoothed, on logarithmic
axes with ordinary numeric tick labels. The horizontal coordinate is the
parameter state after the indicated number of accepted updates.

Reduction and coverage: retain all nine loss curves and their exact 9,225
values and state indices from the prior overview; remove the two diagnostic
rows. The three-column palette, legends, typography and loss-axis formatting
are retained. Page size is 7.16 x 2.55 inches, following the single-row
Analysis024 convention. Source hashes, artist arrays, embedded fonts and PDF
text bounds are checked, followed by visual review of a Poppler render.

Uncertainty and limits: one initialization per model, no uncertainty bands;
descriptive training trajectories, without a stability or causal inference.
This is a presentation change with no new training or statistics.
