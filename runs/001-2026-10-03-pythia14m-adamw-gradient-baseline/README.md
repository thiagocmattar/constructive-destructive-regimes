## Scientific definition

One step is one optimizer update after microbatch accumulation. `g_t` is the
unscaled gradient of the mean causal next-token loss across the actual update's
supervised tokens, before global clipping or AdamW transformations. It includes
all unique trainable parameters. We record every update:

```text
rho_t = <g_(t-1), g_t> / (||g_(t-1)|| * ||g_t||)
S_t = sum_(u=0..t) g_u
A_t = sum_(u=0..t) ||g_u||
B_t = ||S_t||
R_t = B_t / A_t
```

First adjacent cosine is null; zero-norm denominators are null with reasons.
Cancellation with a positive denominator yields a defined zero ratio. The FP64
cumulative vector and FP32 previous gradient have constant memory in update count.
Scalar logs are saved every update; full vector histories are not stored.
Checkpoint recovery states retain both vectors and scalar progress.

These are raw-gradient measurements under AdamW. They do not directly reconstruct
optimizer displacement or establish stability/causality.

## Model, optimizer, and coverage

Pinned random Pythia-14M with the source recipe's small_init/Wang initialization,
ordinary GeLU, no sparsity intervention, and seeds 1234. AdamW: peak `1e-3`, floor
`1e-4`, 1% warmup, betas `(0.9,0.95)`, epsilon `1e-8`, decay `0.1` excluding
bias/LayerNorm, global clipping `1.0`. The source NeoX pre-step scheduler is retained:
the first update has LR zero. FP16 dynamic scaling and FP32 parameters are retained.

Effective batch: 1,024 sequences, implemented with microbatch four plus accumulation.
The final update is smaller. Every complete packed block occurs once in a seeded
permutation; the short tail is appended and processed at its actual length.
There is no padding/wrap/drop. Losses are weighted by supervised targets, including
unequal final microbatches. Full validation also includes its short tail.

Verified local cache: 1,000,000 training documents, 1,491,711,416 input tokens;
500 validation documents, 693,668 input tokens. This implies 728,375 training
sequences including the tail, 712 updates, and a final update of 311 sequences.
There are 1,490,983,041 supervised training targets under within-block causal shift.
The token bytes match the pinned source hashes. These counts were verified during
local preflight; that preflight failed before training because Windows Torch lacks
the required Flash Attention backend.

Tail inclusion and microbatch size differ from the source's wrapped fixed-batch
run. Initialization maps distributions, not bitwise NeoX RNG traversal. Therefore
this is not claimed as an exact framework reproduction of that historical run.
